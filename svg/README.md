# SVG assets

Marcas da Bullet em SVG, para uso por link público. A regra de uso mora no Identity Source, no Bulletpedia: banco Logos e componente Assinatura.

- `bullet_b_icon_*`, `bullet_logo_*`: o símbolo `b.` e o logo `bullet.`.
- `bulletcash_*`, `bulletpay_*`, `bulletpro_*`: os logos de produto.
- `<nome>_logo_*`: logo com nome, o `b.` com o nome ao lado.
- `<nome>_logo_full_*`: a variante do logo com nome, o `bullet.` com o nome embaixo.
- `<nome>_logo_full_2lines_*`: a mesma variante com nome de duas palavras em duas linhas, uma palavra por linha.
- `_white` sobre fundo escuro, `_black` sobre fundo claro.

Os logos com nome saem de `tools/logo_com_nome.py` (com `--duas-linhas` para a variante em duas linhas). Para pessoas, o PNG fica na Biblioteca de marca, no Drive. Logo que já existia fica como era: `arts_logo_white.svg` é o logo próprio da Arts, o mesmo arquivo da Biblioteca de marca.

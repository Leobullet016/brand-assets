# Ferramentas

- `logo_com_nome.py`: gera o logo com nome da Bullet, em curvas, nos quatro arquivos do banco. Roda com Python 3, sem instalar nada: `python3 logo_com_nome.py "nome" --saida pasta`; com `--duas-linhas`, nome de duas palavras ganha também a variante em duas linhas. A regra mora no Identity Source, no Bulletpedia; este arquivo é a forma compilada dela.
- `OFL-OpenSans.txt`: a licença da Open Sans, de onde vêm as letras embutidas no gerador.
